# Young's Portfolio Website

우주에서 가장 뛰어난 AI 개발자, Young의 개인 포트폴리오 웹사이트입니다. HTML, CSS, JavaScript를 사용하여 반응형 디자인과 다양한 인터랙션 기능을 구현했습니다.

## 🚀 주요 기능 (Key Features)

### 1. UX/UI 인터랙션 기능

| 기능                                | 설명                                                                                                                     | 사용 기술                                                        |
| :---------------------------------- | :----------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------- |
| **부드러운 스크롤 (Smooth Scroll)** | 상단 내비게이션 및 TOP 버튼 클릭 시 해당 섹션으로 부드럽게 이동합니다.                                                   | `scrollIntoView({behavior: 'smooth'})`, `event.preventDefault()` |
| **고정 헤더 보정**                  | 고정(Fixed)된 헤더로 인해 섹션 제목이 가려지는 문제를 **CSS `scroll-margin-top` 속성**을 사용하여 깔끔하게 해결했습니다. | CSS `scroll-margin-top`                                          |
| **다크 모드 / 라이트 모드 전환**    | 버튼 클릭 한 번으로 웹사이트 전체 테마를 동적으로 전환합니다.                                                            | JavaScript `classList.toggle()`, CSS 변수(`:root`, `.dark-mode`) |

### 2. 동적 콘텐츠

- **시간대별 인사말 자동 변경**
  - 접속 시간에 따라 `#home` 섹션의 인사말이 **"좋은 아침입니다" (05시~11시)**, **"좋은 오후입니다" (12시~17시)**, **"좋은 저녁입니다" (그 외 시간)** 으로 자동 변경됩니다.
  - JavaScript의 `Date().getHours()`와 조건문을 활용하여 구현했습니다.

## 🛠️ 사용 기술 (Tech Stack)

이 프로젝트는 웹의 기본 기술 스택으로 구성되어 있습니다.

- **HTML5**
- **CSS3** (Custom Properties, Media Queries를 활용한 반응형 디자인)
- **JavaScript (ES6+)**
- **Font Awesome** (아이콘 사용)
